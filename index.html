Event Dashboard

Connect Twitch, configure rewards and test events. Search by name, favorite events or show favorites only. Settings save automatically; presets store different setups.

Set reward names, prices and cooldowns, plus durations or amounts when available.

Solo & Multiplayer

Solo: connect the dashboard to the game using your Switch connection settings.

Multiplayer: start the included server on TCP port 1027. Target selected players or everyone.

Viewer Reward Polls

Twitch caps custom rewards at 50 per channel; other rewards count too. When full, polls let viewers choose inactive events to replace active rewards.

In-Game Mod Menu

Open the pause menu, then choose Mod Menu and configure it like you want to. Press Y to pin or unpin entries and menu categories.

Effect HUD: Choose Off, Full, Icons, Icons + Time, Names or Auto. Auto switches to icons at five visible effects; Full card timers can be toggled.

Activity: Set the feed timeout in seconds; 0 keeps entries until replaced. Instant popups are separate from timed-effect displays.

Installation & Setup

Install the mod, connect the game and Twitch, then test your rewards.

1

Get the release

Download the mod from GameBanana or the public GitHub page below. Use matching Dashboard and Server files from the same release.

2

Install the mod

On Switch, copy the release's atmosphere/ folder to the SD card root. The files should be in atmosphere/contents/0100000000010000/. On an emulator, use its mod folder or mod manager and install the full mod.

3

Start the dashboard

Keep the Dashboard and Server folders together. Run Dashboard/START-DASHBOARD.cmd. If needed, install the dashboard packages listed in Dashboard/PC/requirements.txt. The server requires .NET 10.

4

Connect, set up and test

In the dashboard, choose Solo or Multiplayer, then connect your game and Twitch. For Multiplayer, start the server from the dashboard and choose event targets. Configure your rewards and run a manual test before going live.

Download the Mod

Get the mod from GameBanana or browse its public GitHub repository. Join our Discord for help.

Frequently Asked Questions

Quick answers about setup and compatibility.

What platforms can I use?

On Switch, you need Atmosphère. You can also install the mod with a compatible emulator.

Do the mod, dashboard and server need to match?

Yes. Use all three from the same release.

Does this mod also work with YouTube?

Only Twitch Channel Points are supported at this time.

Why can't I use every event in Multiplayer?

Some events are only available in certain modes. Check the dashboard for availability.

Is the mod still in beta?

Yes. When reporting a bug, include your release, mode, stage, event and any error or crash report.
